# Web Profil Keluarga - Kelompok 3

Repository ini berisi web profil keluarga dari seluruh anggota Kelompok 3.

## Host
Thelma, bertugas mengunduh seluruh project dari GitHub dan mengunggahnya ke server melalui FTP.

## Anggota
1. Thelma - folder `thelma`
2. Beril - folder `beril`
3. Saldi - folder `saldi`
4. Falih - folder `falih`

## Keterangan
- Setiap anggota mengunggah project web profil keluarganya ke foldernya masing-masing.
- Setiap folder memiliki file utama `index.php`.
- Seluruh project digabung menjadi satu folder utama oleh host, lalu diunggah ke server.
